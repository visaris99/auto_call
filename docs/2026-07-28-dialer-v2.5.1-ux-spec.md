## 🔴 안전 (핵심)

### S1. F3 저장이 살아있는 통화를 끊지 않게
- 현재: Save_Click(MainWindow.xaml.cs:1051)이 Dialing/Active에서 EndActiveCallAsync를 먼저 호출 → 통화 종료+저장.
- 변경: **저장(F3)은 `Ended` 상태 + 결과 선택 + (예약결과면)유효 시간일 때만** 실행. Active/Dialing에서 F3 누르면 저장하지 말고 인라인 안내("통화를 먼저 종료(F2)한 뒤 저장하세요"). 결과 버튼은 통화 중에도 미리 선택 가능(유지).
- UpdateCallControls(908-936): 저장 버튼을 결과 미선택 또는 통화중이면 disabled(사후 모달 대신 사전 비활성).

### S2. 통화 중 ADB 유실 시 수동 탈출 경로
- 현재: EndActiveCallAsync가 idle 관측 실패 시 영구 대기 → 세션 잠금, 강제종료가 유일 출구(기록 유실).
- 변경: EndActiveCallAsync(799-831)에서 GetCallStateAsync가 null(장치 미응답)로 idle 확인 실패 시, 경고 대신 YesNo("휴대폰에서 통화가 이미 끝났다면 결과 저장을 진행할까요?") → Yes면 MarkCallEnded()로 Ended 전환(저장 가능). Window_Closing(1296)도 동일 탈출 허용.

### S3. 자동 업데이트 설치 직전 확인 게이트
- 현재: TryAutoUpdateAsync가 다운로드 완료 즉시 무경고 Shutdown+설치(App.xaml.cs:83-89).
- 변경: 설치 시작 전, MainWindow 활성 + 통화 세션 Idle 아니면 보류하고 "지금 설치 / 통화 끝나고 설치" 선택. 로그인 화면이거나 Idle이면 기존처럼 즉시.

### S4. 콜백·상담예약 날짜 포함 입력
- 현재: HH:mm만 받고 과거 시각이면 무경고 익일 전환(QueueLogic.cs:43).
- 변경: 날짜+시간(또는 오늘/내일 명시 선택). 과거 시각 자동 익일 제거 → 과거면 경고. 큐 표시(Ui.cs:84)를 `오늘 14:30`·`내일 09:00`·`07/31 10:00`로. QueueLogicTests 갱신.

### S5. 자동 연락처 열람 제거
- 현재: 리드 선택 즉시 RevealLeadAsync 자동 호출(MainWindow.xaml.cs:574) → 훑어보기도 PII 감사 발생.
- 변경: 단순 선택은 마스킹 유지. **발신 시 or 명시적 '연락처 보기' 클릭 시에만** reveal. (발신 흐름은 어차피 서버 승인+발신이라 그때 열람이 자연스러움)
